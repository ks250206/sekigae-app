# 出力ファイルの手動確認チェックリスト

自動テスト（`src/features/export/*.test.ts`, `tests/e2e/export.spec.ts`）では中身の構造だけを検証している。
見た目・フォント・編集可否はリリース前に以下のアプリで手で確認する。

## 準備

1. `pnpm build && pnpm preview` で起動し、サンプルプロジェクト（部屋 3・約 30 名・昨年度案あり）を用意する。
2. ⑤ 出力で次の 4 ファイルを書き出す。
   - XLSX / 日本語 / 全項目 / 役職で色分け / フロアシート ON
   - XLSX / English / 役職のみ / 色分けなし
   - PPTX / 日本語 / 研究室で色分け / 構成表スライド ON
   - PPTX / English / 性別で色分け
3. オフライン（DevTools の Offline）にしてもう一度書き出せることを確認する（PWA precache）。

## PNG / 印刷

- [ ] PNG: 選択した部屋がフロア上の実位置で並び、見出しと凡例が入る（白背景・ライト配色）。
- [ ] 印刷（Ctrl+P）: UI が隠れ、部屋ごとに 1 ページ（A4 横）、色が印刷される。

## 既知の制約

- PptxGenJS の「はみ出したら縮小」は PowerPoint で文字を編集したときに初めて計算されるため、初期フォントサイズはアプリ側で概算している。
- 非 UTF-8 ロケールの headless Chromium では日本語のダウンロード名が `download` になる（E2E は ASCII 名で検証）。
